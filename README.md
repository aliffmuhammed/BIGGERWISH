# BIGGERWISH Store

A free, no-builder-branding starter storefront for BIGGERWISH.

## Files
- index.html — storefront structure
- style.css — responsive design
- script.js — product filtering and cart

## Free publishing
1. Create a free GitHub account.
2. Create a repository named `biggerwish`.
3. Upload these three files.
4. Open Settings → Pages.
5. Select Deploy from branch → `main` → `/root`.
6. Save.

Your free website will be available at:
`https://YOUR-USERNAME.github.io/biggerwish/`

## Before selling
Replace the sample products, prices and emoji product images with real product photos.
Connect a legitimate payment/order method.
Add your actual shipping, returns, privacy and terms policies.
